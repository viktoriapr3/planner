# Планувальник: Telegram Mini App

Застосунок усередині Telegram: календар і графік дня, гроші та цілі, харчування для сім'ї, кроки, поради.
Працює **безкоштовно і цілодобово**, сервер не потрібен:
- сторінка лежить на **GitHub Pages** (безкоштовно);
- дані кожного користувача зберігаються в **Telegram Cloud Storage**, окремо для кожної людини і теж безкоштовно;
- бот нічого не «запускає», він лише відкриває сторінку кнопкою меню.

## Файли
| Файл | Що всередині |
|---|---|
| `index.html` | каркас сторінки |
| `style.css` | дизайн (підлаштовується під світлу/темну тему Telegram) |
| `app.js` | уся логіка |
| `recipes.js` | база страв (сніданки, супи, гарніри, мʼясо, салати), сюди можна дописувати свої |
| `config.js` | адреса сервера (поки порожня) |
| `server/worker.js` | сервер для нагадувань і спільного планера (Cloudflare Worker) |

## Запуск (≈10 хвилин)

### 1. Викласти на GitHub Pages
1. На GitHub створи новий **публічний** репозиторій, наприклад `planner`.
2. Завантаж у нього 4 файли (`Add file → Upload files`).
3. `Settings → Pages → Build and deployment`: Source **Deploy from a branch**, Branch **main**, папка **/ (root)** → Save.
4. Через 1–2 хвилини з'явиться адреса на зразок `https://твій-нік.github.io/planner/`. Відкрий її в браузері, щоб перевірити.

### 2. Створити бота і прив'язати сторінку
1. У Telegram відкрий **@BotFather** → `/newbot` → придумай назву та юзернейм (має закінчуватися на `bot`).
2. `/mybots` → вибери бота → **Bot Settings → Menu Button → Configure menu button**.
3. Встав адресу з GitHub Pages, потім назву кнопки, наприклад `Планувальник`.
4. Відкрий свого бота: біля поля вводу з'явиться кнопка **Планувальник**, яка відкриває застосунок.

Додатково можна зробити пряме посилання `t.me/твій_бот/app`: у @BotFather виконай `/newapp`, вибери бота й вкажи ту саму адресу.

### 3. Оновлення
Змінила файл на GitHub, і за хвилину зміни вже в Telegram. Дані користувачів при цьому не зникають.

## Як додати рецепт
**В застосунку:** Харчування → Рецепти → «Додати свій рецепт». Рецепт збережеться тільки в тебе.
**Для всіх користувачів:** допиши рецепт у `recipes.js` за зразком (кількості на 1 порцію).

## Що вміє (коротко)
- **Календар:** місяць → клік на день → графік дня (справи з часом, галочки), гроші за день, меню, кроки.
- **Гроші:** доходи й витрати за категоріями, баланс, прогноз «скільки зароблю» (ставка × робочі дні + інше), скільки відкласти (%), цілі з розрахунком на місяць, тиждень і день. Кнопка «Порахувати робочі дні з календаря» рахує дні, де є справа зі словом «робота» або «зміна».
- **Харчування:** кількість людей, продукти-виключення, меню на тиждень або місяць (страву можна замінити 🔄), калорії на людину, список покупок (на весь план або по тижнях, з галочками і копіюванням), «День заготовок»: що і скільки заготовити й заморозити на весь план.
- **Кроки:** ручне введення, ціль, графік за 7 днів, км і ккал (приблизно).
- **Поради:** аналіз твого дня (перетини справ, вільні вікна, невиконане вчора з кнопкою «перенести»), витрат, цілей і кроків, плюс загальні поради з тайм-менеджменту.

## Сервер: нагадування від бота і спільний планер (безкоштовно)
Без сервера все працює, але дані лежать у хмарі Telegram окремо в кожної людини, і бот не може сам написати.
Сервер на **Cloudflare Workers** (безкоштовний тариф, працює цілодобово) додає:
- щовечора повідомлення «На завтра у вас заплановано…»: справи, меню і які заготовки дістати з морозилки (команда `/tomorrow` теж працює);
- **спільний планер** для двох і більше людей: запрошення посиланням, обидва бачать і змінюють те саме.

### Як підключити
1. Зареєструйся на **dash.cloudflare.com**, тариф Free.
2. **Storage & Databases → D1 SQL Database → Create**, назва `planner`.
3. **Workers & Pages → Create → Worker → Hello World**, назва `planner-api` → **Deploy**.
4. **Edit code**: видали все, встав вміст файлу `server/worker.js` → **Deploy**.
5. У воркері відкрий **Settings**:
   - **Bindings → Add → D1 database**: Variable name `DB`, база `planner`;
   - **Variables and Secrets → Add**: тип **Secret**, назва `BOT_TOKEN`, значення — токен бота з @BotFather (нікому його не показуй);
   - **Variables and Secrets → Add**: тип **Text**, назва `WEBAPP_URL`, значення `https://viktoriapr3.github.io/planner/`;
   - **Trigger events → Add → Cron Triggers**: `0 * * * *` (щогодини; бот сам перевіряє, кому о котрій писати).
6. Відкрий у браузері `https://planner-api.<твій-піддомен>.workers.dev/setup`. Має зʼявитися «✅ Готово!» і адреса сервера.
7. Впиши цю адресу в `config.js` у поле `apiUrl` і збережи.

Після цього старі дані з хмари Telegram автоматично перенесуться на сервер при першому відкритті.
У ⚙️ Налаштуваннях зʼявляться годинна нагадувань і кнопка «Створити запрошення».

## Обмеження
- Telegram **не дає доступу** до Apple Health / Google Fit, тому кроки вводяться вручну. Автосинхронізацію можна зробити в окремому застосунку для App Store.
- Калорійність рецептів приблизна.
- Ліміт сховища Telegram: 1024 записи на користувача. Застосунок витрачає ~3 записи на місяць, цього вистачить на багато років.
